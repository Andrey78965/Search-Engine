# Поисковый движок для корпоративного портала «АйТиБокс»

Данный проект представляет собой локальный поисковый движок (аналог поисковых систем Яндекс или Google), разработанный для информационно-новостного портала компании «АйТиБокс». 

Приложение индексирует набор текстовых документов, строит инвертированный индекс и осуществляет поиск по пользовательским запросам. Результаты ранжируются на основе алгоритма расчета абсолютной и относительной релевантности (частоты встречаемости слов). Все конфигурации, запросы и ответы обрабатываются через файлы формата JSON.


##  Основные возможности

* **Инвертированная индексация:** Быстрый поиск по базе документов с использованием частотного словаря.
* **Многопоточность:** Параллельная индексация документов с использованием `std::thread` для ускорения работы с большими объемами данных.
* **Ранжирование результатов:** Расчет абсолютной и относительной релевантности (rank) для выдачи наиболее точных результатов.
* **Гибкая настройка:** Управление параметрами поиска (лимит выдачи, список файлов) через `config.json`.
* **Надежность:** Покрытие бизнес-логики модульными тестами с помощью Google Test.

## Как запустить проект локально

### Требования

- **CMake** версии 3.17 или выше
- **Компилятор C++17** (MinGW / g++)
- **VSCode** с установленными расширениями:
  - **C/C++** (от Microsoft)
  - **CMake Tools** (от Microsoft)
  - **CMake** (для поддержки синтаксиса CMakeLists.txt)

### Шаг 1. Клонирование репозитория

1. Откройте терминал 
2. Выполните команду клонирования:
```bash
git clone <ссылка_на_репозиторий>
cd <название_репозитория>
```

### Шаг 2. Сборка и запуск

#### Способ 1: Через VSCode (рекомендуется)

1. Откройте папку проекта в VSCode (`File → Open Folder → выберите папку search_engine`)
2. Дождитесь автоматического обнаружения CMake-проекта (внизу появится строка состояния CMake)
3. Нажмите на кнопку **Build** в нижней панели VSCode (или `Ctrl+Shift+P → CMake: Build`)
4. После успешной сборки нажмите **Run** (или `Ctrl+Shift+P → CMake: Run`) для запуска приложения

#### Способ 2: Через терминал VSCode (CMake)

Откройте встроенный терминал в VSCode (`Ctrl+``) и выполните:

```bash
# 1. Создайте папку для сборки
mkdir build
cd build

# 2. Сконфигурируйте проект
cmake ..

# 3. Соберите проект
cmake --build .

# 4. Запустите приложение
./search_engine
```

После успешной сборки файл появится в папке build\src\Debug. Запуск из корневой папки:
```bash
build\src\Debug\app.exe
```
